# Anithing API

A Node.js GraphQL API for querying anime data.

This repository contains the backend server. It serves pre-compiled data generated by our automation pipeline.

For the data scraping and mapping tools, see the [anithing-mappings](https://github.com/yashmodi6/anithing-mappings) repository.

## Setup

1. `npm install`
2. `npm run dev`
